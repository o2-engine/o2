## Logging
Для вывода лога используется иерархия каналов вывода в лог `o2::LogStream`. Каждый канал имеет свой строковый идентификатор и список дочерних каналов. 

Вывод в дочерний канал так же выводит и в родительский.

Верхнеуровневыми каналами являются вывод в консоль и в файл. Файл - `log.txt` в рабочей папке, открывается при первом сообщении; `o2Debug.SetLogFile(name)` перенаправляет его, что инструменты, запускаемые из папки приложения, делают до первого сообщения (сборщик ассетов пишет `AssetsBuilder.log`), чтобы не затирать лог приложения.

Можно создавать свои каналы, биндить к другим.

Сообщения лога делятся на 3 типа важности:
- обычное сообщение
- предупреждение
- ошибка
