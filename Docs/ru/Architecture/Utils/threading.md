## Многопоточность
CamelCase-обёртки над стандартными примитивами многопоточности C++, чтобы многопоточный код читался в стиле o2. Заголовки лежат в `Framework/Sources/o2/Utils/Threading/`.

## o2::Thread
Обёртка над `std::thread`; при разрушении автоматически джойнится, чтобы избежать `std::terminate` (по аналогии с jthread). Некопируемый, перемещаемый.
- **Thread(function, args...)** — создаёт и сразу запускает поток.
- **Join()** / **Detach()** — ждёт завершения потока либо отпускает его в независимое выполнение.
- **IsJoinable()** / **GetId()** — работает ли поток и его идентификатор.
- **SleepFor(seconds)** / **SleepForMilliseconds(ms)** / **Yield()** — статические, действуют на текущий поток.
- **HardwareConcurrency()** — количество аппаратных потоков (ядер) или 0, если неизвестно.
- **GetCurrentThreadId()** / **SetCurrentThreadName(name)** — статические; id текущего потока / отладочное имя для профайлеров.

## Мьютексы
- **o2::Mutex** — базовый мьютекс взаимного исключения: `Lock()`, `TryLock()`, `Unlock()`.
- **o2::RecursiveMutex** — тот же API, может повторно захватываться владеющим потоком (нужно столько же раз отпустить).
- **o2::SharedMutex** — множество читателей одновременно или один эксклюзивный писатель: `LockShared()`/`TryLockShared()`/`UnlockShared()` плюс эксклюзивные `Lock()`/`TryLock()`/`Unlock()`.

## Scoped-локи
RAII-обёртки над o2-мьютексами:
- **ScopeLock&lt;T&gt;** — эксклюзивный лок над любым o2-мьютексом; захватывает при конструировании, отпускает при разрушении.
- **SharedLock** — разделяемый (на чтение) лок над `SharedMutex`.
- **UniqueLock** — перемещаемый, управляемый вручную эксклюзивный лок над `Mutex`; можно отпускать и захватывать заново (`Lock`/`TryLock`/`Unlock`/`OwnsLock`) и передавать в `ConditionVariable`. `UniqueLock(mutex, DeferLock{})` ассоциируется с мьютексом, но не захватывает его.

## o2::ConditionVariable
Обёртка над `std::condition_variable`; на время ожидания атомарно отпускает свой `UniqueLock`.
- **Wait(lock)** / **Wait(lock, predicate)** — блокируется до уведомления; предикат защищает от ложных пробуждений.
- **WaitFor(lock, seconds, predicate)** — ждёт, пока предикат не станет истинным или не истечёт таймаут; возвращает итоговое значение предиката.
- **NotifyOne()** / **NotifyAll()** — будит один / все ожидающие потоки.

## o2::Atomic&lt;T&gt;
Lock-free обёртка над `std::atomic`. Некопируемая.
- **Load(order)** / **Store(value, order)** / **Exchange(value, order)**.
- **CompareExchange(expected, desired, order)** / **CompareExchangeWeak(...)**.
- **FetchAdd(value, order)** / **FetchSub(value, order)**, а также операторы `++` / `--`.
- **WaitWhileEquals(old, order)** — блокируется, пока значение равно `old`, до тех пор пока другой поток не изменит его и не вызовет **NotifyOne()** / **NotifyAll()**. Дешёвая альтернатива условной переменной.

## o2::ThreadSafeQueue&lt;T&gt;
Многопроизводительная и многопотребительская FIFO-очередь. Потребители могут блокироваться в ожидании элемента; закрытие очереди будит их, чтобы рабочие потоки могли завершиться.
- **Push(value)** — добавляет элемент и будит одного ожидающего потребителя.
- **TryPop(out)** — неблокирующее извлечение, возвращает false, если очередь пуста.
- **WaitAndPop(out)** — блокируется, пока не появится элемент или очередь не закроется; возвращает false только когда очередь закрыта и пуста.
- **WaitAndPopFor(out, seconds)** — то же самое, но с таймаутом.
- **Close()** / **Reopen()** / **IsClosed()** — закрытие будит всех ожидающих; также **Clear()**, **Count()**, **IsEmpty()**.

## o2::SharedRef&lt;T&gt;
Атомарно подсчитываемый по ссылкам хендл для объектов, пересекающих границы потоков. В отличие от [`o2::Ref`](/Docs/ru/Architecture/Utils/memory.md), у которого счётчик не атомарен и однопоточен, `SharedRef` можно копировать и разрушать в любом потоке. Тип объекта обязан наследоваться от `o2::ThreadSafeRefCounterable`; объекты создаются через **MakeShared&lt;T&gt;(...)** и удаляются, когда исчезает последняя ссылка. Используется для хендлов, которые законно пересекают границу главного/рабочего потока: [джобы](/Docs/ru/Architecture/Utils/jobs.md) и состояние [корутин](/Docs/ru/Architecture/Utils/coroutines.md).

**Правило изоляции:** параллельная работа не должна менять разделяемое состояние `o2::Ref` (сцену, ассеты), поскольку его счётчик ссылок не атомарен. Держите тела воркеров вне графов `o2::Ref` — используйте `SharedRef` для межпоточных хендлов, а обращения к сцене/ассетам откладывайте на главный поток.

<details>
<summary>Пример</summary>

```C++
o2::ThreadSafeQueue<int> queue;

o2::Thread producer([&]()
{
    for (int i = 0; i < 10; i++)
        queue.Push(i);

    queue.Close(); // будит потребителя, чтобы он мог завершиться
});

int value;
while (queue.WaitAndPop(value))
    Process(value);

producer.Join();

o2::Atomic<int> counter{ 0 };
counter.FetchAdd(1);
```
</details>
