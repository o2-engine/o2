## Корутины
`o2::Coroutine<T>` позволяет писать асинхронный код линейно через `co_await`, выполняя его через [систему джоб](/Docs/ru/Architecture/Utils/jobs.md). Возобновления корутины планируются как джобы, поэтому корутина может переходить между главным потоком и параллельными воркерами. Управляющий блок подсчитывается атомарно ([`SharedRef`](/Docs/ru/Architecture/Utils/threading.md)), поэтому хендл корутины безопасно хранить и удалять в любом потоке. Синглтон `CoroutineScheduler` (`o2Coroutines`) обеспечивает пробуждения по времени и на следующий кадр.

Корутины стартуют приостановленными: верните `Coroutine<T>` (или `Coroutine<void>`) из функции, использующей `co_await` / `co_return`, затем запустите её.

## o2::Coroutine&lt;T&gt;
- **Start(thread, priority)** — запускает корутину на выбранном потоке с приоритетом возобновления; повторный вызов не действует.
- **IsDone()** / **IsValid()** — завершена ли / держит ли корутину.
- **Wait()** — блокирует вызывающий поток до завершения. Нельзя на главнопоточной корутине из главного потока — её возобновлениям нужен главный поток.
- **GetResult()** — возвращаемое значение, валидно только после завершения.
- **co_await subCoroutine** — запускает под-корутину (если нужно), приостанавливается до её завершения, затем возобновляется на потоке ожидающего и отдаёт её результат.

## Запуск
- **Async(coroutine, thread)** — запускает корутину на заданном потоке и возвращает её хендл; паттерн «запусти сейчас, дождись позже» для параллельного выполнения нескольких корутин.

## Ожидатели (awaiters)
`co_await` одного из них внутри корутины:
- **SwitchToWorker()** / **SwitchToMain()** — переносит остаток корутины на воркеры / обратно на главный поток.
- **WaitTime(seconds)** — приостанавливает на задержку, возобновляется из таймерного потока шедулера.
- **WaitNextFrame()** — приостанавливает до следующего `OnNewFrame()`.
- **WaitAll(coroutines)** — приостанавливает, пока не завершатся все корутины массива (незапущенные запускаются); неблокирующее ожидание — ожидающий поток продолжает выполнять другую работу.
- **WaitAny(coroutines)** — приостанавливает, пока не завершится любая; возвращает индекс первой завершившейся.
- **o2::Signal** — потокобезопасный примитив ожидания/синхронизации: `co_await signal` (или `signal.Wait()`) приостанавливает; `signal.Synchronize()`, вызываемый из любого потока, освобождает всех текущих ожидающих. Также **IsSignaled()** / **Reset()**. Чтобы дождаться внешнего колбэка, отдайте наружу колбэк, вызывающий `Synchronize()`.

## o2::CoroutineScheduler (o2Coroutines)
- **ScheduleAfter(seconds, action)** — выполнить действие после задержки (основа `WaitTime`).
- **ScheduleNextFrame(action)** — выполнить действие на следующем `OnNewFrame()` (основа `WaitNextFrame`).
- **OnNewFrame()** — срабатывают все пробуждения на следующий кадр; вызывается приложением раз в кадр на главном потоке. На платформах без потоков (WebAssembly) здесь же срабатывают наступившие таймеры `WaitTime`, так как фонового потока-таймера там нет — поэтому `WaitTime` разрешается с точностью до кадра.

На однопоточных платформах корутины работают без изменений — кооперативно на главном потоке через режим нуля воркеров [системы джоб](/Docs/ru/Architecture/Utils/jobs.md).

Ключевой паттерн: стартуем на главном потоке, запускаем N детей на воркерах через `Async`, `co_await WaitAll(children)` (неблокирующее ожидание — главный поток продолжает работу), затем продолжаем на главном потоке с результатами.

<details>
<summary>Пример</summary>

```C++
o2::Coroutine<int> ComputeChunk(int index)
{
    co_await o2::SwitchToWorker();       // тяжёлую часть — на воркере
    int result = HeavyWork(index);
    co_return result;
}

o2::Coroutine<void> ProcessAll()
{
    o2::Vector<o2::Coroutine<int>> children;
    for (int i = 0; i < 8; i++)
        children.Add(o2::Async(ComputeChunk(i))); // запуск на воркерах

    co_await o2::WaitAll(children);       // неблокирующее ожидание на главном потоке

    for (auto& child : children)
        Apply(child.GetResult());         // сбор результатов на главном потоке
}

o2::Async(ProcessAll(), o2::JobThread::Main);
```
</details>
