## Базовые компоненты
В движке есть базовый набор компонент:

- `o2::ImageComponent`  
Обертка над `o2::Sprite` из рендера, умеет все то же самое

- `o2::MeshComponent`  
Обертка над движковым `o2::Mesh`, но с добавлением функционала в редакторе по построению этого меша

- `o2::SkinningMeshComponent`  
2D-меш со скелетным скиннингом. Кости задаются дочерними акторами с `o2::SkinningMeshBoneComponent`. Spine-подобные анимации могут быть сделаны с помощью него

- `o2::SkinnedMeshComponent`  
Рисует скиненную 3D-модель из `SkinnedModelAsset`. Поза задается акторами-костями или встроенным проигрывателем клипов, скиннинг считается на GPU

- `o2::AnimationComponent`  
Компонент анимаций. В нем задается список анимаций, которые могут изменять актор, компоненты и все что есть ниже по иерархии

- `o2::AnimationStateGraphComponent`  
Граф анимационных состояний и переходов между ними

- `o2::SpineComponent`  
Проигрывание анимаций EsotericSoftware Spine, наследник `o2::AnimationComponent`

- `o2::ParticlesEmitterComponent`  
Обертка над партикл-эмиттером из рендера. Умеет все то же самое

- `o2::FlightTrajectoryComponent`  
Полет актора по сплайновой траектории. Сплайн (ширина ключей — коридор случайного смещения) геометрически растягивается между стартовой и финишной точками; прогресс задается анимируемым свойством `position` 0..1 (`SetPosition`), точка траектории пишется в трансформацию актора (виджетам — в офсеты лэйаута) сразу при записи свойства — в том числе при скраббинге в редакторе — и каждый апдейт. Случайное смещение в коридоре меняется только явным `ResetRandomOffset()` (игра вызывает его перед полётом; при скраббинге в редакторе траектория стабильна). Сплайн редактируется в сцене инструментом сплайнов при выборе компонента

- `o2::ScissorClippingComponent`  
Задает отсечение дочерних объектов по своей трансформации. Отсечение работает только на те сущности, которые унаследовали от него приоритет отрисовки

- `o2::ScriptableComponent`  
Компонент в котором можно задать поведение через JS-скрипт

- `o2::SoundComponent`  
Проигрывает звук в позиции актора, управляется в том числе из редактора анимаций

- `o2::SoundListenerComponent`  
Слушатель пространственного звука в позиции и ориентации актора

- `o2::LightComponent`  
Источник света. Позиция и направление берутся из трансформации актора, используется рендер-пассами освещения

- `o2::Mesh3DComponent`  
Рисует 3D-геометрию из `Mesh3DAsset` с трансформацией актора

- `o2::MeshPrimitiveComponent`  
Строит параметрическую 3D-геометрию (бокс, сфера, плоскость, цилиндр)

- `o2::TextSplitterComponent`  
Разбивает текст на символы и создает актор с `o2::TextSymbolComponent` на каждый символ

- `o2::ICollider`: `BoxCollider`, `CircleCollider`, `SplineCollider`, `SplineMeshCollider`  
Физические коллайдеры, работают вместе с актором-телом `o2::RigidBody`
