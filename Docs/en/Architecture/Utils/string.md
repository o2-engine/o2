## String
For convenience there is a wrapper over `std::string` adding useful functionality:

- conversion of basic types to/from string
- `Append` - appends a string at the end
- `Insert` - inserts a string
- `Erase` - removes a range
- `Replace` - replaces a substring with another
- `Find` - searches for a substring
- `Contains` - checks whether a substring is contained
- `CountOf` - counts substring occurrences
- `Starts/EndsWith` - checks whether the string starts/ends with a substring
- `Split` - splits into an array of substrings
- `TrimStart/End` - trims at the start/end
