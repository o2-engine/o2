# PsdTool — PSD import tools + MCP server

Reads PSD documents (structure, rendering, per-layer extraction) and builds o2
actor prefabs replicating the PSD layout. Registered as MCP server `psd` in the
repo root `.mcp.json`.

Dependencies: `pip install psd-tools` (rendering also needs numpy, pulled in
automatically). Regenerating the test PSD additionally needs
`pip install pytoshop six`.

## MCP tools

- `psd_structure(psd_path, include_hidden?)` — layer tree: names, hierarchy,
  kinds, visibility, opacity, blend modes, pixel bboxes. Layers are listed
  bottom-to-top (draw order).
- `psd_render(psd_path, out_path, scale?)` — composite the document into a PNG;
  the result includes a preview image so the model can see the mockup.
- `psd_extract_layers(psd_path, out_dir, layers?, include_hidden?)` — save
  raster layers as RGBA PNGs named after the layers; `layers` filters by name
  or slash path (`Panel/Buttons/PlayBtn`).
- `psd_layer_positions(psd_path, include_hidden?)` — flat placement list: PSD
  bbox/center/size plus o2 world position (origin at canvas center, y up).
- `psd_to_o2_prefab(psd_path, out_dir, assets_root?, atlas?, scale?,
  include_hidden?, name?)` — build an o2 prefab (.proto) mirroring the PSD:
  groups become container actors, raster layers become actors with an
  ImageComponent; hierarchy, layer order (bottom layer = first child), positions,
  sizes and opacity are preserved, hidden layers (with `include_hidden`) come
  disabled. Layer images and their `.meta` files are written into
  `<assets_root>/<out_dir>/`, images are assigned to `atlas`
  (default `Basic.atlas`, pass `""` for standalone textures).

## CLI

```sh
python3 psd_to_o2.py testdata/ui_mock.psd PsdImport/UiMock --assets-root Assets
python3 -c "import psd_lib, json; print(json.dumps(psd_lib.structure('file.psd'), indent=1))"
```

## Coordinates

PSD pixels are top-left origin, y down; o2 world is canvas-center origin, y up.
A layer with bbox center `(cx, cy)` on a `W x H` canvas maps to o2 position
`(cx - W/2, H/2 - cy)`; in the prefab, child positions are relative to the
parent group's bbox center. Actor pivots are `(0.5, 0.5)`.

## Test data

`testdata/ui_mock.psd` is generated by `make_test_psd.py` (pytoshop) and used by
the GameUITests suite `PsdImportUI`, which instantiates the committed demo
prefab `Assets/PsdImport/UiMock/ui_mock.proto` built from it.
