# Архитектура окна AssetsWindow

## Обзор

Окно **AssetsWindow** представляет собой браузер ассетов редактора, предоставляющий визуальный интерфейс для работы с файловой системой проекта. Это окно позволяет просматривать, выбирать, создавать, перемещать и удалять ассеты проекта.

## Основные классы

### 1. AssetsWindow

**Назначение:** Главный класс окна, координирует работу всех компонентов браузера ассетов.

**Ключевые особенности:**
- Singleton - единственный экземпляр в редакторе
- Наследуется от `IEditorWindow`
- Доступен через макрос `o2EditorAssets`

**Основные компоненты:**
- `mFoldersTree` - дерево папок слева
- `mAssetsGridScroll` - область с иконками ассетов справа
- `mSearchEditBox` - поле поиска в верхней панели
- `mSelectedAssetPathLabel` - отображение пути к выбранному ассету в нижней панели

**Функциональные зоны:**
```
┌─────────────────────────────────────────────┐
│  [Search] [Filter]           [Up Panel]     │
├──────────────┬──────────────────────────────┤
│              │                              │
│  Folders     │   Asset Icons Grid           │
│  Tree        │   (AssetsIconsScrollArea)    │
│              │                              │
├──────────────┴──────────────────────────────┤
│  [Tree] Selected Asset Path    [Down Panel] │
└─────────────────────────────────────────────┘
```

---

### 2. AssetsIconsScrollArea

**Назначение:** Область прокрутки с сеткой иконок ассетов, основной компонент для отображения и взаимодействия с ассетами.

**Наследование:**
- `GridLayoutScrollArea` - базовая функциональность grid layout с прокруткой
- `DragDropArea` - поддержка drag & drop операций
- `KeyboardEventsListener` - обработка клавиатурных событий
- `ISelectableDragableObjectsGroup` - управление группой выделяемых объектов

**Ключевые возможности:**
- Отображение ассетов в виде сетки иконок
- Множественное выделение (Ctrl, Shift, прямоугольник выделения)
- Drag & Drop ассетов (внутри окна и между сценой)
- Контекстное меню с операциями над ассетами
- Переименование ассетов inline
- Создание новых ассетов
- Пул иконок для оптимизации производительности

---

### 3. AssetIcon

**Назначение:** Виджет отдельной иконки ассета с поддержкой взаимодействия.

**Наследование:**
- `Widget` - базовый UI виджет
- `SelectableDragableObject` - поддержка выделения и перетаскивания
- `DragDropArea` - возможность принимать drop операции

**Состав:**
- `mAssetInfo` - информация об ассете
- `mNameText` - Label с именем файла
- `mSelectedState` - состояние выделения

**Визуальные состояния:**
- `hover` - курсор над иконкой
- `selected` - иконка выделена
- `focused` - область с иконками в фокусе
- `edit` - режим редактирования имени
- `halfHide` - полупрозрачное состояние (для cut операций)

---

### 4. AssetsFoldersTree

**Назначение:** Виджет дерева папок для навигации по структуре ассетов.

**Компоненты:**
- `mFoldersTree` - внутреннее дерево (тип `FoldersTree`)
- `mContextMenu` - контекстное меню для операций с папками
- `mCurrentPath` - текущий выбранный путь

**Функциональность:**
- Иерархическое отображение папок проекта
- Синхронизация с `AssetsIconsScrollArea`
- Переименование папок inline (двойной клик)
- Контекстное меню с операциями

---

### 5. FoldersTree

**Назначение:** Специализированная версия `Tree` для работы в editor scope.

**Особенность:** Переопределяет `UpdateVisibleNodes()` для работы в editor scope, что необходимо для корректной работы с UI в контексте редактора.

## Основной функционал и его реализация

### 1. Навигация по ассетам

**Реализация:**
- **Открытие папки:** `AssetsWindow::OpenFolder(path)` → устанавливает путь в `AssetsIconsScrollArea` и синхронизирует `AssetsFoldersTree`
- **Двойной клик на папку:** `AssetIcon::OnCursorDblClicked()` → проверяет тип ассета → если папка, открывает её
- **Клик на дереве папок:** `AssetsFoldersTree::OnFoldersTreeSelect()` → вызывает `SetViewingPath()` на scroll area
- **Навигация назад (Backspace):** обрабатывается как в дереве, так и в scroll area

### 2. Выделение ассетов

**Механизмы выделения:**

#### 2.1 Одиночное выделение
- Клик по иконке → `AssetIcon::OnCursorReleased()` → `AssetsIconsScrollArea::OnSelectableObjectCursorReleased()` → обновление `mSelectedAssets`

#### 2.2 Множественное выделение (Ctrl)
- Клик с Ctrl → добавление/удаление из выделения без сброса предыдущих

#### 2.3 Диапазонное выделение (Shift)
- Клик с Shift → выделяет все ассеты между последним выбранным и текущим

#### 2.4 Прямоугольное выделение
- Клик на пустом месте → `BeginSelecting()`
- Движение курсора → `UpdateSelection()` отрисовывает прямоугольник и выделяет пересекающиеся иконки
- Отпускание → `CompleteSelecting()` фиксирует выделение

**Синхронизация:**
- При изменении выделения вызывается `OnAssetsSelected()`
- Обновляется окно Properties (`PropertiesWindow`) с выбранными ассетами
- Вызывается callback `onAssetsSelected` с путями выбранных ассетов

### 3. Drag & Drop

**3.1 Внутри AssetsWindow (перемещение ассетов)**

Последовательность:
1. `AssetIcon::OnDragStart()` → `AssetsIconsScrollArea::BeginDragging()`
2. Создаётся визуальный drag icon (`mDragIcon`)
3. Скрываются выделенные иконки
4. `OnDragged()` → обновление позиции drag icon
5. `OnDropped()` → если drop на папку, перемещает ассеты (`o2Assets.MoveAssets()`)
6. `OnDragEnd()` → показываются обратно иконки

**3.2 Из SceneTree в AssetsWindow (создание прототипов)**

1. SceneHierarchyTree начинает drag объектов сцены
2. Drop в AssetsIconsScrollArea → `OnDroppedFromSceneTree()`
3. Для каждого Actor создаётся `ActorAsset` прототип
4. Сохраняется с расширением `.proto`
5. Пересборка ассетов и выделение созданных

**3.3 Из AssetsWindow в SceneWindow (инстанцирование)**

1. `AssetsIconsScrollArea::OnDragEnter()` в SceneWindow
2. `InstantiateDraggingAssets()` создаёт временные объекты сцены
3. Объекты следуют за курсором
4. При drop регистрируется `CreateAction` в undo системе
5. При exit или cancel → `ClearInstantiatedDraggingAssets()`

### 4. Операции с файлами (Copy/Cut/Paste/Delete)

**Copy/Cut:**
- `AssetsWindow::CopyAssets()` / `CutAssets()`
- Полные пути ассетов помещаются в системный буфер обмена (`Clipboard::CopyFiles()`)
- Cut дополнительно сохраняет список в `mCuttingAssets` и отображает иконки полупрозрачными

**Paste:**
- `AssetsWindow::PasteAssets(targetPath)`
- Получает файлы из буфера
- Создаёт уникальные имена если файл существует (добавляет " copy", " copy2" и т.д.)
- Для cut - перемещает (`FileMove`), для copy - копирует (`FileCopy`)
- Для папок - рекурсивное копирование `CopyAssetFolder()`
- Пересборка ассетов системой

**Delete:**
- `AssetsWindow::DeleteAssets()`
- Вызывает `o2Assets.RemoveAsset()` для каждого
- Пересборка ассетов

### 5. Создание новых ассетов

**Процесс:**
1. Контекстное меню → "Create/[AssetType]" → `AssetsIconsScrollArea::CreateAsset(type)`
2. Создаётся временный ассет (`mNewAsset = type->CreateSampleRef()`)
3. Добавляется в список для отображения
4. Сортируется и прокручивается к новому ассету
5. Запускается inline редактирование имени (`StartAssetRenaming()`)
6. При завершении редактирования → сохранение ассета (`Save()`)
7. Пересборка и выделение созданного ассета

### 6. Переименование

**Inline редактирование:**
1. Двойной клик на имени ассета → `OnAssetDblClick()`
2. Проверка что клик был на nameLabel
3. `StartAssetRenaming()` → активирует состояние "edit"
4. Показывается `EditBox`, текст выделяется
5. При завершении → `o2Assets.RenameAsset()` и пересборка

### 7. Highlight и навигация к ассету

**ShowAssetIcon/HighlightAsset:**
- Открывает папку содержащую ассет
- Прокручивает к ассету
- Запускает анимацию подсветки (`mHighlightAnim`)
- Анимация управляет `mHighlightSprite`, который рисуется поверх иконки

### 8. Интеграция с Properties Window

**Механизм:**
- При выделении ассетов → `OnAssetsSelected()`
- Предзагружаются ассеты (`mSelectedPreloadedAssets`)
- Для `ActorAsset` - передаётся Actor внутри прототипа
- Для обычных ассетов - передаётся сам Asset
- Устанавливается callback `OnAssetsPropertiesChanged()`
- При изменении свойств ассеты автоматически сохраняются

### 9. Контекстные меню

**AssetsIconsScrollArea:**
- Open - открывает ассет в ассоциированном приложении
- Show in folder - открывает папку в проводнике
- New folder - создание новой папки
- Create/[Type] - создание ассетов всех доступных типов
- Copy/Cut/Paste/Delete - операции с файлами

**AssetsFoldersTree:**
- Аналогичное меню для работы с папками
- Операции применяются к текущей выбранной папке

### 10. Оптимизация производительности

**Пул иконок:**
- `mIconsPool` - Map[style → Vector[AssetIcon]]
- `GetAssetIconFromPool()` - переиспользование виджетов
- `FreeAssetIconToPool()` - возврат неиспользуемых
- Шаг расширения пула: 10 виджетов
- Снижает аллокации и инициализацию виджетов

**Виртуализация:**
- `GridLayoutScrollArea` отображает только видимые иконки
- `GetItemsRange()` и `UpdateVisibleItems()` обновляют видимый диапазон
- Невидимые иконки возвращаются в пул

### 11. Сепаратор (Splitter)

**Реализация:**
- `mSeparatorHandle` - `CursorEventsArea` для обработки перетаскивания
- Находится на слое "separator" дерева папок
- При перетаскивании изменяет anchors layout у `mFoldersTree` и `mAssetsGridScroll`
- Сохраняет коэффициент в `mSeparatorCoef` (в будущем в конфиге)

### 12. Анимация показа/скрытия дерева папок

**Механизм:**
- Кнопка в нижней панели переключает `mFoldersTreeVisible`
- `mFoldersTreeShowAnim` анимирует `mFoldersTreeShowCoef` (0...1)
- В callback анимации обновляются anchors обоих панелей
- При коэффициенте < 0.2 дерево скрывается полностью

## Взаимодействие компонентов

### Диаграмма взаимодействия при выборе ассета:

```
User Click
    ↓
AssetIcon::OnCursorReleased()
    ↓
AssetsIconsScrollArea::OnSelectableObjectCursorReleased()
    ↓
AssetsIconsScrollArea::Select() / Deselect()
    ↓
mSelectedAssets обновляется
    ↓
OnAssetsSelected()
    ↓
├─→ Предзагрузка ассетов
├─→ Обновление PropertiesWindow
└─→ Вызов callback onAssetsSelected
    ↓
AssetsWindow обновляет mSelectedAssetPathLabel
```

### Диаграмма открытия папки:

```
User Double-Click на папку
    ↓
AssetIcon::OnCursorDblClicked()
    ↓
AssetsIconsScrollArea::OnAssetDblClick()
    ↓
AssetsWindow::OpenFolder()
    ↓
├─→ AssetsIconsScrollArea::SetViewingPath()
│       ├─→ Загрузка AssetInfo для папки
│       ├─→ Сортировка ассетов
│       └─→ Обновление видимых иконок
│
└─→ AssetsFoldersTree::SelectAndExpandFolder()
        └─→ Синхронизация выделения в дереве
```

### Диаграмма Drag & Drop:

```
User начинает перетаскивание
    ↓
AssetIcon::OnDragStart()
    ↓
AssetsIconsScrollArea::BeginDragging()
    ├─→ Скрыть выделенные иконки
    ├─→ Создать визуальный drag icon
    └─→ Установить mIsDraggingIcons = true
    ↓
OnDragged() (многократно)
    └─→ UpdateDraggingGraphics() - обновление позиции
    ↓
OnDropped() в целевую область
    ├─→ Если в AssetsIconsScrollArea → перемещение ассетов
    └─→ Если в SceneWindow → инстанцирование
    ↓
OnDragEnd()
    └─→ EndDragging() - показать иконки обратно
```

## Особенности реализации

### 1. Editor Scope
Многие операции выполняются в `PushEditorScopeOnStack scope;` - это гарантирует что создаваемые виджеты не попадут в сцену игры.

### 2. Meta-система
Все классы используют систему рефлексии o2:
- `SERIALIZABLE(ClassName)` - сериализация
- `CLONEABLE_REF(ClassName)` - клонирование
- META секции в конце файлов

### 3. Smart pointers
Используется система `Ref<T>` для управления памятью:
- `Ref<T>` - владеющий указатель
- `WeakRef<T>` - слабая ссылка (например, `AssetIcon::mOwner`)

### 4. Асинхронное завершение операций
Drag операции завершаются асинхронно через флаг `mDragEnded` для избежания проблем с обработкой событий.

### 5. Двунаправленная синхронизация
`AssetsFoldersTree` и `AssetsIconsScrollArea` синхронизируются через флаг `mOpengingFolderFromThis` для предотвращения циклических обновлений.

## Расширяемость

### Добавление нового типа ассета:
1. Создать класс, наследующийся от `Asset`
2. Реализовать статические методы:
   - `GetEditorIcon()` - иконка для отображения
   - `GetEditorSorting()` - порядок сортировки
   - `IsAvailableToCreateFromEditor()` - можно ли создавать через UI
   - `GetFileExtensions()` - расширения файлов
3. Зарегистрировать в системе типов
4. Если нужна специальная обработка drag & drop - добавить в `InstantiateAsset()`

### Добавление операций в контекстное меню:
```cpp
mContextMenu->AddItem("New Operation", [&]() { 
    // Реализация операции
}, iconAsset, ShortcutKeys({VK_KEY, VK_MODIFIER}));
```

## Производительность

### Оптимизации:
1. **Пул виджетов** - снижает создание/удаление объектов
2. **Виртуализация** - отрисовка только видимых иконок
3. **Кэширование сортировки** - `Map<AssetInfo, Pair<String, int>>` в `SortAssetInfos()`
4. **Отложенная предзагрузка** - ассеты загружаются только при выделении
5. **Batch операции** - rebuild ассетов вызывается один раз после множественных операций

### Потенциальные узкие места:
- `UpdateAssetsByCurrentPath()` при большом количестве ассетов в папке
- Сортировка при каждом обновлении
- Создание виджетов дерева для глубокой иерархии папок

## Потоки обработки событий

### Клавиатурные сокращения:
- **Ctrl+C** - Copy
- **Ctrl+X** - Cut
- **Ctrl+V** - Paste
- **Delete** - Delete
- **Backspace** - Переход в родительскую папку
- **Ctrl+N** - Новая папка (в контексте дерева)

### События мыши:
- **Одинарный клик** - выделение/снятие выделения
- **Двойной клик на иконке** - открытие/редактирование
- **Двойной клик на имени** - переименование
- **ПКМ** - контекстное меню
- **Drag** - перетаскивание ассетов
- **Прямоугольник выделения** - клик на пустом месте + drag

## Заключение

Архитектура `AssetsWindow` представляет собой хорошо структурированную систему с чётким разделением ответственности между компонентами. Основные принципы:

- **Модульность** - каждый класс отвечает за свою часть функциональности
- **Переиспользование** - пулы объектов, базовые классы UI
- **Расширяемость** - легко добавлять новые типы ассетов и операции
- **Производительность** - виртуализация и оптимизации для больших проектов
- **UX** - богатый функционал взаимодействия (drag&drop, inline editing, контекстные меню)

Система интегрирована с остальными компонентами редактора (Properties, Scene, Tree windows) и предоставляет полноценный инструмент для управления ассетами проекта.
